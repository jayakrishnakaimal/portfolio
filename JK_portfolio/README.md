# JK Portfolio

A personal portfolio website built with React + TypeScript.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Run in development
```bash
npm start
```

### Build for production
```bash
npm run build
```

## Sections

- **Hero** – Introduction and call-to-action
- **About** – Brief bio and background
- **Skills** – Tech stack and competencies
- **Projects** – Showcase of work
- **Contact** – Contact form / links
