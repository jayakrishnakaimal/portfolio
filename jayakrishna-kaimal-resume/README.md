## How to use

1. Open `index.html` in a browser to view the resume.
2. To print or export as PDF: open in Chrome → `File → Print → Save as PDF` → set margins to **None** or **Minimum**.

## Customisation

- Edit text in `index.html`.
- Adjust colours, fonts, or spacing in `style.css`.
- The accent colour is `#1a73e8` (Google Blue) — swap to `#0078d4` for a Microsoft-themed version.
