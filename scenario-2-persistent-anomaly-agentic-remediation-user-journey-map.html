Phase 2
Escalating Pattern Hour 12 – 36
Actor Action / Experience Touchpoint Emotion Pain / Opportunity
Network Ops Second SevOne alert fires — failure rate now 18% on same subnet, persisting for 12+ hours. Ops engineer begins investigation, reviews SevOne dashboard. Pattern is now undeniable. SevOne Performance charts 😟 Concerned
Pain: Must manually correlate SevOne data with INI DHCP/DNS records — no automatic cross-tool view.

Pain: Incident manager learns about the network issue from application complaints, not from proactive network monitoring.
Phase 3
Threshold Breach & Incident Open Hour 36 – 48
Actor Action / Experience Touchpoint Emotion Pain / Opportunity
Network Ops SevOne crosses the 48-hour persistence threshold configured in INI. INI automatically correlates: persistent DNS failures + stale DHCP leases confirmed. Escalation trigger fires. SevOne INI Correlation engine 😰 High stress
Opportunity: This is the automated trigger point — INI + SevOne hand off to Concert and WxO without waiting for human escalation.
Incident Mgr Concert auto-creates a P2 incident. Incident is pre-populated with: SevOne performance charts, INI DHCP staleness data, affected subnet, device count (40), and upstream application impact. No manual data gathering needed. Concert Incident record 😤 Urgent but informed
Opportunity: Pre-populated context dramatically reduces MTTR. Incident manager can immediately assess scope without calling network team.
WxO Agent Concert incident triggers WxO agent. Agent reviews INI DHCP lease data, confirms stale leases are the root cause, checks watsonx.gov policy to confirm it has authorization to act on this subnet and action type. WxO INI watsonx.gov —
Opportunity: watsonx.gov policy check is the guardrail — agent only acts within pre-approved scope. Regulated environments require this audit step.
Phase 4
Agentic Remediation Hour 48 – 48:15
Actor Action / Experience Touchpoint Emotion Pain / Opportunity
WxO Agent Agent executes two actions in INI: (1) Refresh DHCP scope on subnet 10.4.x.x — forces lease renewal for all 40 stale devices. (2) Flush DNS cache for affected records. Both actions logged with full parameters to watsonx.gov audit trail. WxO INI API —
Opportunity: 15-minute remediation window replaces what would have been a 2–4 hour manual triage and fix cycle.
Network Eng Receives a notification that the WxO agent has acted on their behalf in INI. Can review the exact API calls made, parameters used, and watsonx.gov authorization token. Can roll back if needed. INI Action log, watsonx.gov 😌 Relieved, cautious
Pain: Engineers need visibility and rollback capability — trust in autonomous action requires a clear audit trail and override path.
Network Ops SevOne shows DNS failure rate dropping in real time as devices renew leases. Ops engineer watches the recovery curve without needing to take manual action. SevOne Live dashboard 😌 Relieved
Opportunity: This is the "invisible UI" moment — the engineer observes recovery without performing it. The agent is the interface.
Phase 5
Validation & Closed-Loop Confirmation Hour 48:15 – 49
Actor Action / Experience Touchpoint Emotion Pain / Opportunity
WxO Agent Agent queries SevOne after 15 minutes: DNS failure rate returned to baseline (<0.5%). Validation passed. Agent writes resolved network state back to INI — DHCP leases fresh, DNS records valid. SevOne INI WxO —
Opportunity: Automated validation loop — agent confirms its own work succeeded before declaring done. No human check-back required.
Incident Mgr Concert incident automatically updated with remediation steps, validation result, and resolution timestamp. Incident closed as P2 → Resolved. Full audit trail attached. SLA timer stopped. Concert Incident timeline 😌 Satisfied
Opportunity: MTTR drops from hours to under 1 hour. SLA compliance maintained. Post-incident report auto-generated from Concert audit data.
Network Ops SevOne alert clears. Ops engineer reviews the closed incident in Concert and confirms recovery. No further manual action needed. SevOne Concert 😊 Confident —
Phase 6
Learning & Prevention Post-incident
Actor Action / Experience Touchpoint Emotion Pain / Opportunity

Opportunity: Human-in-the-loop at the learning stage — engineer improves the system after the agent demonstrated the failure mode.
WxO Agent Agent pattern (DHCP staleness → DNS failure → flush + renew) is promoted to a persistent skill in the WxO catalog. Next occurrence will trigger remediation at hour 12, not hour 48. WxO Skill catalog —
Opportunity: The loop shortens with each cycle. The system gets faster at recognizing and resolving this pattern class.
Incident Mgr Concert generates a post-incident summary: time to detect, time to remediate, SLA impact, root cause, and prevention action taken. Shared with stakeholders automatically. Concert Report 😊 Confident
Opportunity: Automated post-incident reports replace manual write-ups — freeing the incident manager for higher-value work.

Journey Summary
Pain Points
  • No proactive cross-tool correlation in Phase 1–2
  • Manual log-in to INI required to confirm DHCP staleness
  • Incident manager learns about network issue from app complaints, not monitoring
  • Engineers need visible rollback path to trust agent actions
Design Opportunities
  • Lower "watchlist" threshold in INI before SevOne escalates
  • Auto-correlate SevOne DNS failures with INI DHCP lease state
  • Pre-populate Concert incidents with full cross-tool context
  • Expose agent audit trail and one-click rollback in INI UI
Value Delivered
  • MTTR: ~4 hrs manual → ~1 hr automated
  • Zero manual remediation steps for network team
  • Full audit trail for compliance and post-incident review
  • Pattern promoted to WxO skill — future incidents resolve at hour 12
